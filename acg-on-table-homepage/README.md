# ACG On Table — GitHub Pages Package

This folder is a complete static website that can be uploaded directly to GitHub Pages.

- `index.html` — application homepage
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `styles.css` — shared website styles
- `assets/` — optimized website images

## Verify Before Publishing

1. Confirm that `cnhjr230329@outlook.com` is a working email address that you monitor.
2. Confirm that the app provides an account deletion option. If it does not, implement one before App Store submission or revise the deletion instructions so they match the actual process.
3. Confirm that the data types, uses, retention practices, and service features described in the Privacy Policy accurately match the released app.

## GitHub Pages URLs

If the files are uploaded to an `aot/` folder in a `<username>.github.io` repository, the URLs will normally be:

- Homepage: `https://<username>.github.io/aot/`
- Privacy Policy: `https://<username>.github.io/aot/privacy.html`
- Terms of Service: `https://<username>.github.io/aot/terms.html`

With a custom domain such as `legal.gfunny.club`, the URLs can be:

- `https://legal.gfunny.club/`
- `https://legal.gfunny.club/privacy.html`
- `https://legal.gfunny.club/terms.html`
